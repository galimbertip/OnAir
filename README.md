# GPverse OnAir

Studio di registrazione per podcast nel browser: regia (sigla, sottofondo, capitoli), teleprompter con segnali, re-take istantaneo, mixer con EQ, video con effetto contorni ed export MP3/WAV per Spotify e WebM per YouTube.

**Apri:** https://galimbertip.github.io/OnAir/

- Funziona su PC (Chrome/Edge), tablet e smartphone Android; si installa come app e va anche senza internet.
- File audio, registrazioni e testi restano sul dispositivo: nulla viene caricato online.
- Versioni: vedi [CHANGELOG.md](CHANGELOG.md) (schema V.maior.minor.patch). Istruzioni: [LEGGIMI.md](LEGGIMI.md).
